# Community Code of Conduct

The **Mustaqbalat** project maintains a serious, disciplined engineering environment for contributors, reviewers, and issue reporters.

---

## 1. Expected Professional Standards

All participants interacting across `Issues`, `Pull Requests`, and code reviews are expected to:
- Keep discussions strictly focused on technical accuracy, code quality, performance metrics, and documentation clarity.
- Deliver constructive, evidence-based engineering feedback while respecting contributor effort.
- Provide clear, reproducible details and target URLs when reporting incompatible websites or bugs.
- Maintain formal, respectful communication free of personal attacks, harassment, or off-topic spam.

---

## 2. Unacceptable Behavior

- Personal insults, harassment, or derogatory conduct toward any contributor or user.
- Publishing private information belonging to others (such as personal contact details or secret authentication tokens).
- Submitting intentionally malicious code, tracking scripts, or changes violating project security invariants.

---

## 3. Enforcement & Contact

Repository maintainers review reported violations and take appropriate corrective action (warning, editing/removing offending comments, or blocking accounts when necessary). Report violations directly to [`algorithm-platforms.figment413@passinbox.com`](mailto:algorithm-platforms.figment413@passinbox.com).
