# 🌙 مستقبلات للراحة البصرية | Mustaqbalat

**مستقبلات للراحة البصرية (`MustaqbalatLilRahaAlBasariyya`)** هي أداة خفيفة جداً (أقل من `40 KB` بالكامل بدون أي مكتبات خارجية ثقيلة) تعمل كإضافة متصفح حديثة (**Manifest V3**) وأيضاً كـ **إضافة ويب فورية بدون استهلاك أي مساحة تخزين (0 Bytes Bookmarklet / Userscript / Web Studio)**.

---

## ✨ المميزات الرئيسية

1. **التشغيل الافتراضي على كل الصفحات مع تحكم مخصص لكل موقع:**
   - تعمل تلقائياً فور التثبيت على جميع صفحات الويب (`<all_urls>`) مع إمكانية استثناء أو تخصيص أي موقع بنقرة واحدة.
2. **تقليل أو زيادة سطوع الشاشة وطبقات التعتيم (`Overlay Layers`):**
   - التحكم بالسطوع من **20% (تعتيم ليلي عميق)** إلى **150% (رفع الإضاءة والتباين)**.
   - وضع **طبقات شفافة فوق الموقع نفسه (`Overlay`)** بمعزل تام داخل `Shadow DOM` حتى لا تتأثر تنسيقات المواقع.
   - التحكم بتخفيف وهج اللون الأبيض وتصفية الضوء الأزرق وتشبع وطيف ألوان الصفحة.
3. **دعم كامل لملفات الـ PDF وقارئ مدمج بدون تثبيت:**
   - تعتيم ملفات الـ PDF المفتوحة في المتصفح (`embed[type="application/pdf"]`) مع خيار تعتيم إضافي والوضع الداكن الخاص بالـ PDF.
   - يتضمن **قارئ ومعتّم ملفات PDF مدمج بالذاكرة المؤقتة (`extension/pages/pdf-viewer.html`)** يفتح أي ملف PDF محلياً في `RAM` دون استهلاك أي مساحة على القرص.
4. **الوضع الداكن الذكي لأي صفحة (`Smart Dark Mode`):**
   - أوضاع متعددة: **داكن ذكي (يحفظ ألوان الصور والفيديوهات دون عكسها سلبياً)**، **داكن دافئ للقراءة**، **داكن عميق AMOLED**، و**داكن مخصص لملفات PDF**.
5. **لوحة الألوان المتقدمة (`HEX` وعجلة الألوان التفاعلية):**
   - إدخال مباشر لأي كود لوني سداسي **`#HEX`**، عجلة ألوان تفاعلية (`Canvas Color Wheel`)، أشرطة `RGB`، قطّارة الألوان من الشاشة (`EyeDropper`)، أنماط دمج الطبقات (`Multiply`, `Soft-Light`, `Darken`, `Color`)، و8 لوحات راحة بصرية جاهزة.
6. **مراقبة استهلاك النظام داخل الصفحة + لوحة إحصائيات الأيام والأسابيع:**
   - **مؤشر حي داخل الصفحة (`In-Page HUD`)** يعرض استهلاك الأداة الفعلي بالـ `KB`، زمن المعالجة بالمللي ثانية (`ms`)، وسلاسة الإطارات (`FPS`).
   - **لوحة إحصائيات متكاملة (`extension/pages/dashboard.html`)** تعرض رسوماً بيانية وجداول تفصيلية لحجم الاستهلاك ومدة التشغيل عبر **7 أيام، 14 يوماً، 4 أسابيع، و8 أسابيع**.
7. **ربط مباشر مع `GitHub Issues` والمواقع غير المتوافقة:**
   - إرسال المشكلات والمواقع التي لم تستجب أو رفض المتصفح تشغيل الإضافة عليها مباشرة إلى مستودع GitHub (`Mohamed7AbdELhalim/Mustaqbalat/issues`) مع تعبئة تلقائية للرابط والإعدادات، بالإضافة إلى سجل محلي للمواقع المستثناة.
8. **⚡ أداة التحويل إلى إضافة ويب بدون تنزيل أو مساحة تخزين (`Zero-Disk-Space Converter`):**
   - **Bookmarklet (0 بايت على الجهاز):** سحب وإفلات لشريط الإشارات في المتصفح ليعمل على أي موقع بدون تنزيل أي ملف.
   - **Userscript (`.user.js` ~9 KB):** يعمل تلقائياً على جميع المواقع (`*://*/*`).
   - **حازم الإضافة بالذاكرة المؤقتة (`.zip`):** يحوّل ويحزم الإضافة لمتصفحات Chrome / Edge / Brave و Firefox مباشرة داخل المتصفح بحجم ~38 كيلوبايت فقط.

## 🚀 التشغيل السريع محلياً أو عبر الويب

لا يحتاج المشروع إلى تثبيت أي حزم خارجية (`0 npm dependencies`):

```bash
# تشغيل المنصة الحية ومحوّل إضافة الويب
npm start

# التحقق الآلي من سلامة ملفات الإضافة وأداة التحويل
npm test
```

## 🧩 هيكل المشروع

- `extension/` — ملفات إضافة المتصفح الكاملة (Manifest V3):
  - `manifest.json` — إعدادات الصلاحيات والتشغيل الافتراضي على كل الصفحات والإطارات.
  - `core/mustaqbalat-engine.js` — المحرك الأساسي المشترك للتعتيم والطبقات والـ PDF والوضع الداكن ومؤشر الاستهلاك.
  - `popup/` — نافذة التحكم الموحدة (السطوع، عجلة الألوان وHEX، الاستهلاك، وربط GitHub).
  - `pages/dashboard.html` — لوحة إحصائيات الاستهلاك اليومي والأسبوعي.
  - `pages/pdf-viewer.html` — قارئ ومعتّم ملفات PDF الفوري بالذاكرة.
- `converter/` — محرك التحويل إلى إضافة ويب بدون مساحة (`Bookmarklet`, `Userscript`, وحازم `.zip` في الذاكرة).
- `index.html` & `studio.js` — المنصة التفاعلية الحية لتجربة الإضافة وتحويلها مباشرة من المتصفح.
