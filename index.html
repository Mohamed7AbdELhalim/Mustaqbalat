الفصل الأول: الفيزيولوجيا البصرية وتأثير الإضاءة الرقمية

تعمل إضافة مستقبلات على وضع طبقات تعتيم وتلوين مباشرة فوق عارض ملفات الـ PDF في المتصفح (سواء عبر <embed type="application/pdf"> أو القارئ المدمج)، مما يتيح لك خفض وهج الصفحات البيضاء أو تحويل المستند للوضع الداكن المخصص لملفات PDF بنقرة واحدة.

لتجربة فتح أي ملف PDF موجود لديك بدون تنزيل أي برامج، اضغط على زر "فتح ملف PDF حقيقي" بالأعلى.

⚡ أداة تحويل "مستقبلات" إلى إضافة ويب بدون تنزيل أو استهلاك مساحة

صُممت هذه الأداة خصيصاً للأجهزة ذات المساحة المحدودة جداً: اختر إعداداتك المفضلة بالأسفل، ثم حوّل الأداة فوراً في ذاكرة المتصفح إلى إضافة ويب سحب وإفلات (0 بايت على القرص)، أو سكربت تلقائي لكل المواقع، أو حزمة إضافة مضغوطة فائقة الصغر (~38 كيلوبايت فقط).

1. إضافة ويب فورية بالسحب والإفلات (Bookmarklet)

لا تتطلب تنزيل أي ملف إطلاقاً! اسحب الزر البرتقالي أدناه إلى شريط الإشارات (Bookmarks Bar) في متصفحك، واضغط عليه في أي موقع لفتح لوحة التعتيم والألوان والـ PDF فوراً.

🌙 مستقبلات — راحة بصرية
حجم السكربت: ~8.5 كيلوبايت فقط

2. إضافة ويب تلقائية على جميع الصفحات (Userscript)

تعمل تلقائياً وبشكل افتراضي على كل المواقع وملفات الـ PDF فور فتحها عبر مدير السكربتات الخفيف (Violentmonkey / Tampermonkey / Stay للهواتف) دون فك ضغط أي مجلدات.

// @match *://*/*
// @match file:///*.pdf
// تشمل: السطوع + الطبقات + الوضع الداكن + HEX + مؤشر الاستهلاك + ربط GitHub
الحجم الكامل للحزمة: ~38 كيلوبايت (أصغر من صورة أيقونة!)

3. محوّل حزمة المتصفح المباشر بالذاكرة (Chrome / Edge / Firefox)

يجمع ملفات الإضافة الكاملة داخل ذاكرة المتصفح مباشرة مع إعداداتك المخصصة بصيغة Manifest V3 جاهزة للتحميل بدون أي أدوات بناء.
