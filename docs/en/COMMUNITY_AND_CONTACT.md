### Sponsorship Role & User Outreach Scope
The **Community on Murtakiz (`مجتمع مرتكز`)** serves as the **Official Community Sponsor** of **Mustaqbalat (Visual Comfort & Screen Dimmer)**. Its concrete role for the project encompasses:
1. **Showcasing the Project on the Community Page:** Features Mustaqbalat directly on its community page so members and visitors interested in open-source Arabic utilities can discover it immediately.
2. **Introducing Users to What Mustaqbalat Is:** Explains to users the exact technical purpose of Mustaqbalat—an open-source tool for reducing or boosting screen brightness, applying viewport dimming layers, Smart Dark Mode, and `HEX` screen tints across websites and `PDF` documents while monitoring daily and weekly resource consumption.
3. **Guiding Users on Low-Storage Devices:** Informs users with tight disk space that they can run Mustaqbalat via the Zero-Disk-Space Web Add-on Converter (`0-byte Bookmarklet` / `Userscript`) without downloading heavy installers.
4. **Connecting Users to Issue & Development Workflows:** Directs users encountering incompatible websites or proposing enhancements to the official `GitHub` issue tracker.

- **Murtakiz Platform & Community Link:** [`https://murtakiz.com`](https://murtakiz.com) *(ready for direct sub-path customization whenever the specific community slug is updated without altering documentation structure)*.

### How to Add or Replace the Official Qabilah (or Murtakiz) Logo
The repository includes a dedicated customizable logo directory at `assets/sponsors/` pre-wired into `README.md`, `README.en.md`, and this directory so you can drop in Qabilah's official logo at any time:
1. **Using an `SVG` Logo:** Overwrite `assets/sponsors/qabilah-logo.svg` with the official SVG file using the exact same filename (`qabilah-logo.svg`). All Arabic and English Markdown pages will render the new logo immediately.
2. **Using a `PNG` or `WebP` Logo:** Place the image inside `assets/sponsors/` (e.g., `assets/sponsors/qabilah-logo.png`) and update the image extension from `.svg` to `.png` inside `README.md` and `README.en.md` (`./assets/sponsors/...`) as well as this file (`../../assets/sponsors/...`).
