# المرجع التفصيلي سطراً بسطر لملفات الإعداد بصيغة JSON

وفق المعيار الرسمي `RFC 8259` لملفات `JSON`، يُحظر إدراج تعليقات `//` أو `/* */` داخل ملفات `.json` لأن ذلك يتسبب في رفض المتصفحات (`Chrome` / `Firefox`) لتحميل `manifest.json` ورفض `Node.js` لقراءة `package.json`. ولإتمام توثيق كل سطر في المستودع دون استثناء، يوثق هذا المرجع كل سطر من الأسطر الـ `117` الموزعة على ملفات الإعداد الأربعة، وعلاقته بالسطر السابق، وارتباطه ببقية وحدات المشروع.

> **ملاحظة:** جميع ملفات البرمجة والتنسيق والواجهات الستة عشر الأخرى (`10,088` سطراً موزعة على `.js`, `.css`, `.html`, `.yml`) مشروحة سطراً بسطر مباشرة داخل ملفاتها المصدرية نفسها دون حذف أي سطر كود أصلي.
